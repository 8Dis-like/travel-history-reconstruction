Motivation

The Problem

Passport stamps are the primary record of international travel, but manual history reconstruction is slow, error-prone, and linguistically demanding.

⏱
Processing Bottleneck
Stamps are not chronologically ordered. Manual reconstruction becomes error-prone as stamp counts grow.
🌎
Language Barrier
190+ nations, different languages, Gregorian & Hijri calendars. No officer can reliably parse all variants.
🔍
Visual Degradation
Stamps overlap, suffer faded ink and aging — challenging for automated detection.
Research Gap

No widely available solution reliably generalizes across varying stamp designs. Prior work (Zaaboub et al., 2020) relies on structure-dependent methods failing on real-world degraded pages.

🏢 Industry Need (Securiport)

Securiport requires an automated document intelligence solution to scan passport pages, localize stamps, and reconstruct structured travel timelines.

Literature

Background & Related Work

Object Detection
YOLO Family → YOLOv26 (2016–2025)
Single-shot real-time detectors. YOLOv26 adds segmentation head, improved recall — backbone of our detection stage.
Document AI
LayoutLM / Donut / DocVQA (2020–2022)
Document models leveraging layout structure. Fail on faded, rotated, multilingual stamps without clean OCR.
Zaaboub et al. (2020) — Closest Prior Work
Neural network stamp classification. Structure-dependent — does not generalize across diverse country designs or degraded ink.
Language Models & VLMs
Transformers / Attention (Vaswani et al., 2017)
Foundational attention enabling VLMs (Claude, Gemini) to understand visual context holistically without structured OCR.
Segmentation
U-Net / ResNet-34 Instance Segmentation
Used to recover 490 additional stamps that Otsu thresholding couldn't cleanly separate — enabling our dataset expansion.
✦ Our Novel Approach

Combine YOLOv26 instance segmentation for precise stamp localization with a config-driven VLM extraction layer — moving beyond structure-dependent OCR to holistic visual understanding. Each component specializes, improving robustness on degraded, rotated, multilingual stamps.

Experiment 3

System-Level Evaluation

End-to-end evaluation on 5 real passports. Reveals a critical cascading accuracy problem — strong components do not guarantee a strong timeline.

⛓ The Cascading Error Problem

A stay record is correct only if: (1) every stamp detected, (2) every field extracted correctly, (3) entry/exit paired correctly, AND (4) chronological position is right. One wrong field flips a confirmed stay to flagged.

🔑 Central Finding

The ~27-point gap between stamp-level accuracy (62.3%) and system timeline accuracy (35.8%) is stable — confirmed in two independent evaluation rounds. Reconstruction logic is the pipeline's primary bottleneck.

Summary

Conclusions

Major Contributions
📊
Dataset Expansion via U-Net
381 → 871 stamps. Overlap-aware dataset. YOLOv26 real-world Recall: 83.3% → 94.8%. F1: 0.859 → 0.927.
🤖
VLM-over-OCR, Validated Empirically
Config-driven BaseExtractor factory supporting Claude, Gemini, local stubs. Concrete evidence for VLM superiority over traditional OCR on degraded stamps.
💻
Review-First Frontend
React/Ant Design interface pairing every timeline entry with source stamp and page. Color-coded flags, edit-and-rebuild loop — a triage tool, not a black box.
⚠ Known Limitations
→ System timeline accuracy (35.8%) far below components
→ Small system eval (5 passports) — direction not bounded
→ English-only evaluation — multilingual untested
→ Cross-stamp contamination not isolated as metric
Positioning for Securiport

Deploy as a human-in-the-loop triage and transcription aid. Detection alone already boxes every stamp — the core manual bottleneck. Analyst review via the frontend ensures accuracy until reconstruction improves.

Geographic plausibility checks, better handling of unrecoverable dates, wider system-level test set to improve on the 35.8% baseline.

Dedicated experiment measuring accuracy on contaminated vs. clean crops — quantifying this failure mode's contribution to the 27-point gap.

Expand annotated real passport set beyond 194 pages and 5 full passports for tighter accuracy estimates.

Arabic, Cyrillic, CJK support — target only after reconstruction stage is no longer the dominant error source.
